Install as Full-Screen Phone App

When hosted on GitHub Pages, this web app includes a built-in PWA Manifest so it installs directly onto your home screen and launches in true 100% full screen without browser bars:

Android (Chrome / Edge / Brave)

Tap the browser menu (⋮) in the top-right corner and select "Install app" or "Add to Home screen".

iPhone / iPad (Safari)

Tap the Share button at the bottom of Safari, scroll down, and tap "Add to Home Screen".
